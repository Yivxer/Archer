# Archer 文案风格指南

_三端统一规范 · 2026-05-19_

## 原则

1. **短句优先**：UI 文案 ≤ 10 字，帮助文案 ≤ 15 字，错误提示 ≤ 12 字
2. **不说废话**：去掉"当前""暂""请先"等冗余修饰，保留核心语义
3. **行动导向**：错误提示告诉用户下一步做什么，而非描述问题本身
4. **语气一致**：安静、直接、不过度客气、不堆砌

## 核心品牌文案

| 位置 | 文案 |
|------|------|
| 首页标题 | Archer |
| 首页副标题 | Archer 是一个长期理解你的灵魂伴生体。 |
| 英文主文案 | Archer is not a tool for everything. It is a companion for becoming yourself. |
| 输入占位 | 想聊什么？ |
| 终端欢迎 | Archer {version} · 于时间的荒原里，为自己建一座神庙。 |

## 状态标签（≤ 4 字）

| 状态 | 标签 |
|------|------|
| 已连接 | 已连接 |
| 连接中 | 连接中 |
| 缺少 token | 缺少口令 |
| token 不匹配 | 口令不匹配 |
| 终端未启动 | 终端未启动 |
| 其他错误 | 未连接 |

## 帮助文案（≤ 15 字）

| 状态 | 帮助 |
|------|------|
| 缺少 token | 在设置中填入本地 API 的连接口令。 |
| token 不匹配 | 口令与终端启动参数不一致。 |
| 终端未启动 | 先启动终端（archer.py），再点重试。 |
| 其他错误 | 检查本地 API 或模型配置。 |
| 预览模式 | 当前为预览模式。 |

## 空状态（≤ 6 字）

| 场景 | 文案 |
|------|------|
| 无记忆 | 暂无记忆 |
| 无待确认记忆 | 无待确认记忆 |
| 无已确认记忆 | 尚无已确认记忆 |
| 无匹配结果 | 无匹配{类型} |
| Soul 文件空 | 此文件未配置路径或为空。 |
| 无会话 | 暂无会话 |

## 三端圆环视觉

统一使用 5 色 conic-gradient：
```css
conic-gradient(from 195deg, #5ee8e0, #1e7be8, #f5c842, #f5612a, #e8212a, #5ee8e0)
```

- `--cyan: #4dd9d4` · `--blue: #1e7be8` · `--amber: #f5c842` · `--orange: #f5612a` · `--red: #e8212a`
