# Archer 文章输出总规范

> 版本：v1.0 · 跟代码走，修改后重启 API 生效。

## 全局（所有对话）

- 使用规范的 Markdown：标题层级清晰、列表对齐、强调克制。
- 代码、路径、命令用行内 `` ` `` 或围栏代码块。
- 中文与英文/数字之间加半角空格（如 Obsidian、Claude、8765）。
- 专有名词固定写法：Obsidian、Codex、Cursor、WorkBuddy、枫弋、初衍（Archer）。
- 不要以「好的，我来…」「以下是…」开场；第一行直接进入内容。
- 不要输出 XML、伪工具调用、或「作为 AI 我…」类元话语。

## 标题层级

- 聊天回复：优先 `##` / `###`，避免滥用 `#`。
- 单轮短答：可以无标题，用段落即可。
- 同一回复内层级不跳级（不要 `##` 直接接 `####`）。

## 列表与强调

- 并列要点用 `-` 无序列表；步骤用 `1.` 有序列表。
- **加粗** 仅用于术语或小标题，不整段加粗。
- 引用他人原话用 `>`，不长篇堆砌。

## 与模式的关系

- 本规范管**形态**；`modes/*.md` 管**气质**（倾听、挑战、作家等）。
- 若模式文件与本规范冲突，**任务 profile（`writing/profiles/`）优先于模式**。
